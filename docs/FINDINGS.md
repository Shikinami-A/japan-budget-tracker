# 初回調査メモ（2026年10月8日）

この資料では、簗和生氏の発言・国交省への問い合わせという個別の事実関係と、他制度の予算増減から抽出した確認候補を区別します。現時点で、追加の政治的な働きかけを立証した事案はありません。全省庁の地域別・事業別・執行額の網羅調査も未完了です。

## 道路予算：同じ地域でも事業主体・対象範囲で符号が変わる

[国交省の精査結果](https://www.mlit.go.jp/road/content/002025983.pdf)（2026年10月6日）は、2026年2月中旬の簗議員からの問い合わせと、その後の配分額の説明を記載しています。削減の働きかけの有無に関する本人・国交省の説明は、報道記事や会見記録の確認と分けて扱う必要があります。予算表だけから圧力の有無を結論しません。

| 対象 | 2025当初 → 2026当初の想定国費（百万円） | 国交省公表の増減率 |
| --- | --- | ---: |
| 那須烏山市が実施する事業 | 142 → 105 | −26.2% |
| 那須烏山市内の県事業 | 183 → 287 | ＋56.6% |
| 那須烏山市内の両者合計 | 325 → 392 | ＋20.5% |
| 那珂川町が実施する事業 | 49 → 23 | −54.1% |
| 那珂川町内の県事業 | 213 → 297 | ＋39.6% |
| 那珂川町内の両者合計 | 262 → 319 | ＋22.0% |

那須烏山市の「64%減」は、2025年度までに整理した事業だけで2026年度を集計した値。2026年度の新規3事業を加えると26.2%減です。表の金額は百万円に丸められており、表示値から計算した率と公表率には端数の差があります。

これらは交付金の**要素事業の想定国費**です。国は社会資本総合整備計画単位で配分を決め、計画内の要素事業への配分は自治体の裁量に委ねられています。対象事業と決定主体を明確にする必要があります。

[栃木県の国会議員一覧](https://www.pref.tochigi.lg.jp/a51/documents/20260413152401.pdf)（4月1日）は栃木3区の議員を渡辺真太朗氏（無所属）、簗和生氏を比例（自由民主党）と記載。簗氏を現在の栃木3区小選挙区議員として割り当てることは避けています。

普通交付税の出典は[2025年の大綱](https://www.soumu.go.jp/main_content/001022039.pdf)と[2026年の大綱](https://www.soumu.go.jp/main_content/001083398.pdf)。[愛知県の説明](https://www.pref.aichi.jp/soshiki/zaisei/2026kohuzei.html)は億円表示の丸め値から183.3%と記載しており、上表の百万円表示から計算した183.6%と精度が違います。

農水省の出典は[2025年度配分](https://www.maff.go.jp/j/budget/kasyo/7tousyo/index.html)と[2026年度配分](https://www.maff.go.jp/j/budget/kasyo/8tousyo/index.html)。各行の具体的PDF URL・交付金表はダッシュボードから確認できます。PDF番号は年度で地域がずれているため、都道府県名で結合しています。

防衛省の出典は[2025年度実施計画](https://www.mod.go.jp/j/approach/chouwa/hojokin/r7-1/10.pdf)と[2026年度実施計画](https://www.mod.go.jp/j/approach/chouwa/hojokin/r8-1/10.pdf)。全国の対象は73施設・120市町村から76施設・122市町村に変わっており、対象追加を政治的な増額と混同しません。

## 全国総額・執行額でわかること

一般会計の19所管の当初予算はすべて増加または新設です。ただし、所管内の個別事業や地域配分が減っていないことを示すものではありません。2025補正後と2026当初を比べると大きな「減」が多く見えるため、参考比較に分離しました。

14特別会計34勘定等も当初同士で確認。例えば先端半導体・人工知能関連技術勘定の歳出総額は332,800 → 1,239,004.417百万円、約272.3%増です。これは会計総計の変化で、特定自治体への配分や議員の影響を直接示しません。所管別・地域別分解が必要です。

[2026年度第1四半期の支出状況](https://www.mof.go.jp/policy/budget/08_1a.pdf)は前年同期も掲載しています。環境省の支出は54,716.464 → 31,474.328百万円と約42.5%減、経済産業省は211,827.028 → 306,622.035百万円と約44.8%増。支出時期・繰越・事業段階を確認するための手がかりで、年間予算の減額・増額や政治的な配分の証拠ではありません。

[2025年度7月分](https://www.mof.go.jp/policy/budget/report/revenue_and_expenditure/fy2025/0707b.html)と[2026年度7月分](https://www.mof.go.jp/policy/budget/report/revenue_and_expenditure/fy2026/0807b.html)の所管別支出済額も比較しました。4〜7月累計の一般会計総額は約42.25兆円から45.67兆円へ約8.1%増です。環境省は76,259.536 → 51,665.454百万円（約32.3%減）、経産省は263,413.465 → 351,979.987百万円（約33.6%増）。第1四半期との増減率の違いも支出期間で変わるため、地域への年間配分の増減とは区別します。7月末累計には第1四半期を含み、合算しません。

[2025年度決算概要](https://www.mof.go.jp/policy/budget/budger_workflow/account/fy2025/ke080731.pdf)の一般会計支出済歳出額は129兆4,661億円。2026年度年間決算と並べられる段階ではないため、四半期比較と別表示しています。

## 政治的な働きかけの検証に必要な追加資料

要望・申請額と配分率、採択・不採択理由、整備計画別決定額と自治体による要素事業への配分、当時の議員・首長の所属党・選挙結果、問い合わせ・面会・決定記録、過去数年の系列が必要です。現在の議員名簿と2年度だけの金額から、党派による優遇・報復を推定する集計は実施していません。
