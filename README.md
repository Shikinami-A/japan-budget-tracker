# japan-budget-tracker

日本の2025年度・2026年度の予算と地域配分を、出典・集計範囲・地域の国会議員と一緒に確認する静的ダッシュボードです。**調査継続中であり、全省庁の全事業・全自治体・全執行額を網羅したものではありません。**

## 起動・確認

Python 3.11以上、Node.js 22以上。アプリの実行にnpm依存パッケージ、APIキー、外部CDNは不要です。

```sh
python3 scripts/build_data.py
npm test
npm start
```

ブラウザーで `http://127.0.0.1:8000/` を開きます。HTMLのダブルクリックではJSONの読み込みができないことがあるため、HTTPで配信してください。`npm start`はローカルループバックにだけバインドします。

地域・所管・制度・議員名で絞り込み、増減率・増減額・同制度との差のしきい値を調整できます。「出典・議員」で全員の情報、公式説明、確認した本文、比較上の留意点を表示。CSVはページ内の20行だけでなく、**現在のフィルターに一致する全行**を出力します。

任意の実画面検証には、インストール済みのPlaywrightとChromiumを使います（通常の実行・CIには不要）。

```sh
python3 scripts/check_ui.py
```

Chromiumの場所を指定する場合は `BUDGET_BROWSER_PATH` を使用してください。

## 調査の結果と限界

[調査メモ](docs/FINDINGS.md)に、道路予算の集計範囲の違い、他制度の確認候補、公式説明を記載しています。増減だけで政治的な働きかけを認定しません。申請額、採択基準、事業の完了・進捗、制度変更、災害、需要などを確認し、決定記録と合わせて検証する必要があります。

10月9日の継続調査で、通信権限を付けたコマンドから既存プロキシ経由の財務省HTTP 200と原本取得を確認しました。照合記録には131の原本URLを収録しています。財務省CSV ZIP4本の目別明細から一般会計19所管・特別会計34勘定を独立集計し、PDFでも確認。普通交付税、農水省2交付金、厚労省・防衛省の収載金額と道路資料も原本照合しました。静岡2026の2件の欠損を解消しました。

原本を取得したことと、全省庁・全自治体を網羅したことは別です。全国の地域別・事業別配分と執行額、全地域の党籍確認は未完了です。厚労省の参考比較は2025の「内示額」と2026の「計画額」で名称・更新時点が異なります。議員・党籍資料は10月8日の照合記録を維持し、予算調査の更新日で新しく見せません。

原本取得のための環境設定と今回の通信実測は[通信許可の追加手順とホスト一覧](docs/NETWORK_SETUP.md)を参照してください。環境状態ツールの適用状態は未確認で、到達成功は実際の取得結果として記録しています。

[比較方法](docs/METHODOLOGY.md)、[未確認事項・次の調査](docs/RESEARCH_STATUS.md)をご覧ください。省庁別の調査状況は画面にも表示します。特別会計の歳出総計や会計間の繰入は一般会計と合算しません。合計行と内訳行、複数地域にまたがる事業の二重計上にも注意します。

## 出典と再現

- `data/source-text/`：数値を確認した公式本文の必要部分。連絡先など調査に不要な情報は削除。
- `data/party-profile-evidence.json`：レビュー済みの個別党籍照合。議員ID・院・選挙区、根拠URLと抽出本文のハッシュを保存。
- `scripts/build_data.py`：単位変換・地域名による結合・名簿の整理。農水省PDFの番号は都道府県コードではありません。
- `public/data.json`：比較行、出典URL、公表日・取得日、抽出本文のSHA-256、比較条件、未取得値。
- `data/*original-verification.json`・`data/reviewed-mlit.json`・`data/mof-structured-verification.json`：原本取得日時・原本SHA-256・表位置・独立照合記録。
- `scripts/validate_data.py`：全国総額の照合、地域の丸め誤差、出典・欠損・名簿の検証。

出典の`sha256_extracted_text`は**保存した抽出本文のハッシュ**です。原本の`original.sha256_original`と分けて表示・保存し、CSVにも原本記録を含めます。取得日時はUTC、調査日は日本時間。元の検索抽出本文・その取得日は維持しています。PDF抽出には欠落・並び替えがあり得るため、取得だけで数値照合済みとは扱いません。

公式ファイルの通信許可が利用できる環境では、以下の手順で原本をキャッシュに保存できます。外部取得はCI・画面の表示時には実行しません。

```sh
python3 scripts/fetch_sources.py --limit 5
```

今回の範囲を再取得・再照合する場合はPopplerの`pdftotext`も必要です。取得先は公式ホストに限定し、リダイレクトも検査します。これらの調査コマンドはCIでは実行しません。`--fetch`を省くと保存済み原本と取得証跡を使います。

```sh
python3 scripts/fetch_sources.py --limit 20
python3 scripts/verify_core_originals.py
python3 scripts/verify_maff_originals.py --fetch
python3 scripts/verify_grants_originals.py --fetch
python3 scripts/verify_mlit_originals.py --fetch
python3 scripts/verify_mof_structured.py --fetch
python3 scripts/verify_monthly_originals.py --fetch
python3 scripts/build_data.py
npm test
```

通常ビルドはコミット済み照合記録だけを読み、原本キャッシュやネットワークに依存しません。原本バイナリは`.cache/originals/`へ保存し、Git・Pages公開対象から除外します。

この取得スクリプトは政府・自治体の許可済みホストのみを対象とします。党の名簿ページは対象外です。所属党の照合元と取得本文は`data/source-text/party-*.txt`とJSON内の`party_evidence`に保存しています。CSVにも議員名簿の資料日・URLと所属党の確認記録を含めます。

## 公開リポジトリの安全対策

詳しい方針は [SECURITY.md](SECURITY.md)。以下を実装しています。

- 静的ファイルのみ。認証・サーバーAPI・データベース・投稿フォーム・アクセス解析を持ちません。
- 外部JavaScript・CDN・フォント・広告を読み込まず、画面からの通信は同一オリジンのJSONのみ。
- 本文は`textContent`で表示。`innerHTML`・`eval`を使わず、外部リンクはHTTPS限定、別タブに`noopener noreferrer`を付与。
- CSPでスクリプト・通信先等を制限し、CSVには数式インジェクション対策を実施。
- `.env`、秘密鍵、調査キャッシュ、実画面検証の生成物をGitから除外。APIキーを画面やActionsに組み込みません。
- GitHub Actionsは完全なコミットSHAで固定。通常CIは`contents: read`のみ、チェックアウト認証を保持しません。`pull_request_target`は使いません。
- 公開するのは`public/`のみ。Pagesの書き込み権限とOIDCは公開ジョブにだけ付与。

公開前にGitHubのSecret scanning / Push protectionを有効にし、秘密情報をコミットしないでください。漏えいした認証情報は履歴からの削除だけでなく失効・再発行が必要です。

## GitHub Pages

この変更の作成時点では、Pagesを公開していません。リポジトリの `Settings → Pages → Source` を `GitHub Actions` に設定し、レビュー済みの変更を `main` に反映後、`Publish reviewed static dashboard` ワークフローを手動実行できます。

ワークフローは`main`からの手動実行のみを公開対象とします。公開する場合はJSON内の公的議員情報・出典・未確認事項も誰でも取得できることを確認してください。ホスティングでレスポンスヘッダーを設定できる場合の追加設定は[SECURITY.md](SECURITY.md)に記載しています。
